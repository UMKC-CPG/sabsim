# Submission guide — si_si

Si(100)/Si(100) small demo, 50 eV Ar, DPA-3.1-3M

Generated by `sabsim prepare` (DESIGN.md §10). Each script fills
the stage folder of the same name: deliverables beside this guide,
bulk output under `intermediate/` (§10.8). Submit the jobs in the
order below, checking each result before submitting the next
(§10.2). Each script also prints, on success, what to check and
the next job to submit.

## Step by step

1. `sbatch prep_surf1_si.slurm` (prep_surf1; independent — submit in either order, or together)
2. `sbatch prep_surf2_si.slurm` (prep_surf2; independent — submit in either order, or together)
3. `sbatch bond_si_si.slurm` (bond; after `prep_surf1_si` and `prep_surf2_si` have finished and been checked)
4. `sbatch analysis_si_si.slurm` (analysis; after `bond_si_si` have finished and been checked)

## Chained form, for a person who trusts the gates

Submit everything at once and let the scheduler hold each job
until the ones it depends on succeed (`afterok`):

```bash
prep_surf1_id=$(sbatch --parsable prep_surf1_si.slurm)
prep_surf2_id=$(sbatch --parsable prep_surf2_si.slurm)
bond_id=$(sbatch --parsable --dependency=afterok:$prep_surf1_id:$prep_surf2_id bond_si_si.slurm)
analysis_id=$(sbatch --parsable --dependency=afterok:$bond_id analysis_si_si.slurm)
```
